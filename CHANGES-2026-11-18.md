# Tigermax Jobs update, 18 November 2026

## How to upload
1. Unzip `tigermaxjobs-2026-11-18.zip`.
2. On GitHub (tigermaxjobs/tigermaxjobs) click Add file > Upload files, drag in everything inside the unzipped folder (including `.github`), and commit. Render redeploys automatically.
3. In Supabase > SQL Editor, paste and run `supabase/migrations/20261118_career_intelligence.sql` once.
4. In Render > Environment, add `CERTIFICATE_SECRET` (any long random string). Never change it later, or existing certificates stop verifying.
